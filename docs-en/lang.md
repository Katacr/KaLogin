# Language Files

KaLogin language files are located at:

```text
plugins/KaLogin/lang/
```

Default files:

| File | Language |
|---|---|
| `zh_CN.yml` | Simplified Chinese |
| `en_US.yml` | English |

Change the language in `config.yml`:

```yaml
language: "en_US"
```

After editing language files, run:

```bash
/kl reload
```

For dialog body content, see [UI Customization](features/ui.md).
