# KaLogin v1.4.0 更新日志

## 版本信息

- **版本号**: 1.4.0
- **发布日期**: 待定

---

## 中文

### 新增

- **注册成功执行动作**：玩家注册成功后可自动执行预设动作，方便联动其他插件或发放奖励。
- **登录成功执行动作**：玩家登录成功后可自动执行预设动作，可用于欢迎消息、权限处理或其他自动化流程。
- **邮箱绑定功能**：新增邮箱绑定与验证码校验能力，可用于账号安全增强与密码找回。

### 说明

- 本次更新主要围绕账号流程扩展与安全性增强。
- 建议更新后检查配置文件中的新增选项，并按需完成相关设置。

---

## English

### Added

- **Actions on registration**: preset actions can run automatically after a player registers, which makes linking other plugins or granting rewards easier.
- **Actions on login**: preset actions can run automatically after a player logs in, useful for welcome messages, permission handling or other automation.
- **Email binding**: added email binding with verification-code validation for account security and password recovery.

### Notes

- This release focuses on extending the account flow and improving security.
- After updating, review the new configuration options and set them up as needed.
